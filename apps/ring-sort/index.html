Ring Sort - Color Game

Puzzle game for Android

Sort coloured rings onto pegs until every peg holds one colour.

Get it on Google Play Privacy policy

Move the top ring from any peg onto an empty peg or onto a ring of the same colour. In harder levels size matters too, so a larger ring can't sit on a smaller one.

Start with two colours and work up to four-colour puzzles with size rules. There's no clock, so take your time.

What's inside

  • Easy and Hard modes, with size rules in Hard
  • Undo, move counter and level select
  • Progress saves automatically
  • Haptic feedback and smooth ring animations
  • Plays offline
